## 2. Component Details & Usage

### A. SHA-256 Audio & Session Hashing (`hashing.py`)
Converts audio evidence and session parameters into an irreversible 64-character hexadecimal digest:
$$\text{Audio File} \xrightarrow{\text{SHA-256}} \text{Digital Fingerprint}$$

```python
from security.hashing import hash_data, hash_audio_file, hash_session_data

# Hash raw audio bytes
audio_hash = hash_data(raw_audio_bytes)

# Hash an audio file on disk (streamed in 64 KB chunks)
file_hash = hash_audio_file("suspicious_call.wav")

# Hash session metadata deterministically
session_hash = hash_session_data({
    "session_id": "session_001",
    "caller": "+919876543210"
})
```

---

### B. Tamper-Evident Hash Chain (`hash_chain.py`)
Connects events sequentially so each block embeds the hash of the preceding block:
$$\text{Event 1} \rightarrow \text{Hash 1}$$
$$\text{Event 2} + \text{Hash 1} \rightarrow \text{Hash 2}$$
$$\text{Event 3} + \text{Hash 2} \rightarrow \text{Hash 3}$$

```python
from security.hash_chain import HashChain

chain = HashChain()

# Event 1: Call started
e1 = chain.add_event(
    session_id="session_001",
    event_type="CALL_STARTED",
    risk_score=0,
    model_version="w2v2-aasist-v1",
    audio_hash="e3b0c442...",
)

# Event 2: Suspicious voice detected
e2 = chain.add_event(
    session_id="session_001",
    event_type="SUSPICIOUS_VOICE",
    risk_score=82,
    model_version="w2v2-aasist-v1",
    audio_hash="9f86d081...",
)
```

Every event adheres to the standardized schema:

```json

  "timestamp": "2026-09-19T11:00:00Z",
  "event_type": "SUSPICIOUS_VOICE",
  "risk_score": 82,
  "model_version": "w2v2-aasist-v1",
  "audio_hash": "sha256_hash_here",
  "previous_event_hash": "previous_hash_here",
  "event_hash": "current_hash_here"
}
```

---

### D. Integrity Verification (`integrity.py`)
Verifies the cryptographic chain and isolates any modification:

```python
from security.integrity import verify_hash_chain, detect_tampering

# Verify complete chain
is_valid, message = verify_hash_chain(chain)
print("Chain Valid?", is_valid)  # True

# Simulate malicious tampering
chain.tamper_event(1, "risk_score", 10)

is_valid, message = verify_hash_chain(chain)
print("Chain Valid?", is_valid)  # False (Tamper detected at index 1!)
```
